## Prompts UI

Prompt:

You are a React developer tasked with creating a frontend for Lexi, an AI Legal Assistant.
Goal: Let users upload a contract (PDF/text), analyze its clauses, and see AI-generated explanations of risks. Make legal work accessible, fun, and fast.

Functional requirements:

File upload (PDF or text).

Display extracted clauses in a scrollable, collapsible list.

Show AI-generated risk explanations next to each clause.

Allow users to highlight clauses or mark important risks.

Show a summary of key risks at the top.

Responsive layout for desktop and mobile.

UI / Design guidelines:

Clean, professional, approachable look.

Use soft colors and clear typography for readability.

Use cards or panels for individual clauses.

Include hover effects or expand/collapse animations for better interaction.

Show loading spinners or progress indicators when AI is analyzing.

Include a call-to-action button to re-analyze or upload a new document.

Accessible design: sufficient contrast, readable font sizes, and keyboard navigation.

Technical requirements:

Implement with React (functional components + hooks).

Use modern styling (CSS modules, styled-components, or Tailwind CSS).

Include state management for uploaded files, clauses, and AI responses.

Keep the code modular, clean, and ready to integrate with a backend AI service.

Output a complete React component or app with all UI elements, interactions, and styling included. Include placeholders where AI-generated explanations will appear.
